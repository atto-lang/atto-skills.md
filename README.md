# AttoLang AI Skills

Portable, task-focused Markdown instructions for AI coding agents working with [AttoLang](https://github.com/atto-lang), an actor-first systems language.

This repository uses the [Agent Skills](https://agentskills.io/specification) directory convention (`skills/<name>/SKILL.md`). Language documentation is a moving target; distinguish draft language semantics from compiler-tested implementations, and validate generated `.atto` against the selected backend.

The skills catalog and validation tooling are being introduced through reviewable pull requests.
